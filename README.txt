# Exic TOPUP Store — Free Website Starter

Open `index.html` in a browser to preview the website.

Included:
- Exic TOPUP Store logo
- Responsive gaming-store homepage
- Game/product cards
- Nepalese NPR example prices
- Product/package selection
- UID / Game ID fields
- Cart
- Login/register front-end demo
- Payment-ready checkout flow
- eSewa/Khalti/bank sections can be added after you provide the public payment details/QR images

Important:
- This is a front-end starter. Login data is only stored in the browser for demonstration; it is NOT a real secure account system.
- Do not collect or store customers' game passwords. Use UID/Player ID and Server ID only.
- Replace example prices with your actual rates before publishing.
